# 🛍️ React E-Commerce Filtering App

An elegant and performant e-commerce product filtering app built with **React** and **Tailwind CSS**. Users can browse and filter products by **search**, **category**, **color**, and **price**. The UI is clean and responsive, with state-driven logic for fast, dynamic filtering.

---

## 📸 Demo

[Click here to see Live Demo](https://robinranga.github.io/react-advance-filtering/)

---

## 🧰 Tech Stack

- ⚛️ **React** – UI & component logic
- ⚡ **Vite** – Blazing-fast dev/build tool
- 🎨 **Tailwind CSS** – Utility-first styling
- 🧠 **useState + Filtering logic + useContext** – For dynamic state-driven updates
- 📦 **Local Object Data** – Shoes, sandals, flats, etc.

---

## ✨ Features

- 🔍 **Search bar** to quickly find items
- 🧭 **Sidebar filters** by:
  - **Category** (e.g. Shoes, Sandals, Flats)
  - **Color**
  - **Price Range**
- ⚡ Instant filtering with no reloads
- 💅 Clean, responsive UI with Tailwind CSS
- 🧼 Easy-to-understand state management with `useState`

## 📦 To run it locally

### 1. Clone the repo

```bash
git clone https://github.com/robinranga/react-advance-filtering.git
cd react-advance-filtering
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the dev server

```bash
npm run dev
```
